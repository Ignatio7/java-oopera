# 🎭 OOpera — Система управления театром

Объектно-ориентированная модель театра с иерархией персонала и типов постановок.

## О проекте

OOpera — учебный Java-проект, моделирующий структуру театра с помощью принципов ООП. В проекте реализована иерархия классов для персонала (режиссёры, актёры) и репертуара (опера, балет, мюзикл).

Проект написан в рамках курса **«Java-разработчик»** от Яндекс Практикума. Основная цель — освоить ключевые принципы объектно-ориентированного программирования: наследование, полиморфизм и инкапсуляцию.

## Функциональность

- Создание и управление театральными постановками разных жанров
- Хранение информации о режиссёрах и актёрах
- Полиморфная работа с объектами разных типов через общий интерфейс

## Технологический стек

- **Java** — основной язык
- **ООП** — наследование, полиморфизм, инкапсуляция, абстракция
- **GitHub Actions** — CI (автоматическая сборка)

## Структура проекта

```
Theatre/
├── People/
│   ├── Person.java      # Базовый класс: имя, возраст, пол
│   ├── Actor.java       # Актёр (наследует Person)
│   ├── Director.java    # Режиссёр (наследует Person)
│   └── Gender.java      # Перечисление: пол (MALE / FEMALE)
│
├── Shows/
│   ├── Show.java        # Абстрактный базовый класс постановки
│   ├── Opera.java       # Опера (наследует Show)
│   ├── Ballet.java      # Балет (наследует Show)
│   └── MusicalShow.java # Мюзикл (наследует Show)
│
└── Main/
    └── Main.java        # Точка входа
```

## Диаграмма наследования

```
Person
├── Actor
└── Director

Show (abstract)
├── Opera
├── Ballet
└── MusicalShow

Gender (enum)
└── MALE / FEMALE
```

## Принципы ООП в проекте

| Принцип | Реализация |
|---------|-----------|
| **Наследование** | `Actor` и `Director` наследуют `Person`; `Opera`, `Ballet`, `MusicalShow` наследуют `Show` |
| **Инкапсуляция** | Поля классов закрыты, доступ через геттеры/сеттеры |
| **Полиморфизм** | Работа с объектами `Opera`, `Ballet`, `MusicalShow` через тип `Show` |
| **Абстракция** | Базовые классы определяют общий интерфейс |

## Запуск

**Требования:** Java 11+

```bash
git clone https://github.com/Ignatio7/java-oopera.git
cd java-oopera
# Компиляция
javac -d out Theatre/People/*.java Theatre/Shows/*.java Theatre/Main/*.java
# Запуск
java -cp out Main
```
